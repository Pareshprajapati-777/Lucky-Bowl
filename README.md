# 🥣 Lucky Bowl 🎉

> ✨ An ultra-realistic **3D Lucky Draw experience** with a glass bowl, hand-picking interaction, and animated paper unfolding.

## 🎯 About

**Lucky Bowl** is an interactive web experience that makes lucky draws more engaging and cinematic. Pick a lucky paper from the realistic 3D glass bowl and reveal the result with smooth animations.

## ✨ Features

- 🥣 **3D Glass Bowl** with a realistic visual style
- ✋ **Hand-Picking Interaction** for selecting a lucky paper
- 📜 **Paper-Unfolding Animation** for the final reveal
- 🎬 **Smooth Animations** powered by GSAP
- 🎊 **Confetti Celebration** for the lucky result
- ⚡ **Vite-Powered** development and build setup
- 📱 **Interactive Browser Experience**

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| 🟨 **JavaScript** | Core application logic |
| 🌐 **HTML / CSS** | UI and styling |
| 🧊 **Three.js** | 3D graphics and rendering |
| 🎞️ **GSAP** | Animations and transitions |
| 🎊 **Canvas Confetti** | Celebration effect |
| ⚡ **Vite** | Development and build tooling |

## 🚀 Run Locally

### 1️⃣ Clone

```bash
git clone https://github.com/Pareshprajapati-777/Lucky-Bowl.git
cd Lucky-Bowl
```

### 2️⃣ Install

```bash
npm install
```

### 3️⃣ Start

```bash
npm run dev
```

Open the local URL shown by Vite in your browser.

## 🎮 How It Works

**1. 🥣 Enter** → Explore the 3D lucky bowl  
**2. ✋ Pick** → Select a lucky paper  
**3. 📜 Unfold** → Watch the reveal animation  
**4. 🎊 Celebrate** → Enjoy the winner effect
